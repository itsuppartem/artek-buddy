# Support

## Reporting bugs

If something in Artek Buddy is broken, reproducible, or unexpected:
- Search existing [GitHub Issues](https://github.com/itsuppartem/artek-buddy/issues) first to avoid duplicates.
- Open a new issue using the [Bug report template](https://github.com/itsuppartem/artek-buddy/issues/new?template=bug.yml).
- Include product version (`VERSION`), host OS/architecture, minimal reproduction steps, and redacted logs (never paste tokens, keys, or passwords).

## Security vulnerabilities

Do **not** report security vulnerabilities in public GitHub issues.
Follow [SECURITY.md](SECURITY.md) to report privately via maintainer email or GitHub Private Vulnerability Reporting.

## Feature ideas and architecture

Product feature proposals and architecture improvements can be opened using:
- [Feature request template](https://github.com/itsuppartem/artek-buddy/issues/new?template=feature.yml) for user-facing changes.
- [Engineering template](https://github.com/itsuppartem/artek-buddy/issues/new?template=engineering.yml) for CI, quality, performance, or security evidence.
