# 5. Hand-written SQL migrations, not Alembic

## Status

Accepted.

## Context

Schema changes are infrequent and small. Postgres is the only database.
Fifteen numbered files already exist under `src/artek_buddy/db/migrations/`.

## Decision

Keep ordered `.sql` files applied by `HistoryStore.apply_migrations()`. Do
not add Alembic (or a second migration tool) unless we abandon this runner
on purpose.

The runner splits each file with `split_sql_statements` (quotes, `--` /
`/* */` comments, dollar-quoted bodies). That is still not a reason to
introduce Alembic.

## Consequences

Reviewers read SQL, not autogenerated diffs. Replay on an empty database is
the test, not a shadow ORM.
