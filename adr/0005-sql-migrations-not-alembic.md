# 5. Hand-written SQL migrations, not Alembic

## Status

Accepted.

## Context

Schema changes are infrequent and small. Postgres is the only database.
Fifteen numbered files already exist under `src/artek_buddy/db/migrations/`.

## Decision

Keep ordered `.sql` files applied by `HistoryStore.apply_migrations()`. Do
not add Alembic (or a second migration tool) unless we abandon this runner
on purpose.

The runner still splits each file on `;`. That is a known sharpness (issue
on the migration runner). It is not a reason to introduce Alembic in the
same change as documenting the choice.

## Consequences

Reviewers read SQL, not autogenerated diffs. A statement that contains `;`
inside a string is a footgun until the runner is hardened. Replay remains
the test, not a shadow ORM.
