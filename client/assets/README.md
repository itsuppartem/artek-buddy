# Artek Buddy marks

Original marks for the Linux `.deb` and the product window. The face is the
owner's tricolor Cavalier (black ears, white blaze, tan eyebrows). The lying
pose with the toy is pairing only. Toy colors stay out of chrome.

| File | Use |
| --- | --- |
| `app-icon.png` | GTK window, `notify-send`, pixmaps |
| `hicolor/*/apps/artek-buddy.png` | Desktop launcher (`Icon=artek-buddy`) |
| `web/bot-mark.png` | Bot avatar (face) |
| `web/pairing-mark.png` | Pairing card (lying pose) |
| `web/favicon.png` | Window tab / document icon (glyph) |

Do not replace these with a third-party character sheet.
