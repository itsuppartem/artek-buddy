# Artek Buddy marks

Original mascot for the Linux `.deb` and the product window. Not a licensed
character and not a copy of one.

The animal is a cartoon bandicoot. The costume is ours: charcoal tech vest,
teal **A** badge, one headphone, teal inner ears, amber eyes, a short
side-swept lightning tuft. No jeans. No gloves.

| File | Use |
| --- | --- |
| `app-icon.png` | GTK window, `notify-send`, pixmaps |
| `hicolor/*/apps/artek-buddy.png` | Desktop launcher (`Icon=artek-buddy`) |
| `web/bot-mark.png` | Bot avatar on the color badge |
| `web/pairing-mark.png` | Pairing card |
| `web/favicon.png` | Window tab / document icon |

Do not replace these with a third-party character sheet.
